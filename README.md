# 우리집 배치연구소 v4

정적 HTML 가구 배치 도구입니다.

## 파일
- `index.html`: 화면과 가구 배치 기능
- `floorplan.jpg`: 기본 예시 59A 아파트 도면

## v4 주요 기능
- 아파트 도면 이미지 업로드 및 기본 59A 도면 불러오기
- 알려진 길이를 기준으로 도면 크기 보정
- 거실, 안방, 작은방 등 여러 방의 배치 영역을 각각 등록
- 작업할 방을 선택한 뒤 해당 방 안에서 가구 추가
- 방에 속한 가구는 해당 방 경계 안에서만 이동·회전·크기 수정 가능
- 가구 복제, 삭제, 가격 합계, 배치도 PNG 저장

## 사용 순서
1. 도면 이미지를 불러옵니다.
2. STEP 2에서 실제 길이를 기준으로 크기를 보정합니다.
3. STEP 3의 새 방 이름에 `거실`을 입력하고 `이 방 영역 그리기`를 누릅니다.
4. 도면에서 거실 벽 안쪽의 꼭짓점을 차례로 클릭하고 `영역 확정`을 누릅니다.
5. `안방`, `작은방` 등으로 이름을 바꿔 각 방 영역을 반복해서 등록합니다.
6. `작업할 방 선택`에서 가구를 배치할 방을 고른 뒤 STEP 4에서 가구를 추가합니다.

도면의 벽과 방은 자동 인식하지 않습니다. 사용자가 각 방의 경계를 직접 클릭해 지정해야 합니다. 이 버전은 브라우저 내 임시 작업용이며, 새로고침하면 배치 상태가 저장되지 않습니다. 배치도 PNG 저장 기능으로 결과 이미지를 보관할 수 있습니다.
