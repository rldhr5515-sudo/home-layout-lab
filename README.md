## v17 이미지 파일 업로드
- 실제 파일 선택 버튼으로 PNG/JPG/WEBP 사진을 등록합니다.
- 사진은 브라우저에서 최대 1200px, JPEG 품질 82%로 최적화해 저장합니다.
- 상품을 도면에 배치하면 업로드 이미지가 가구 영역 안에 표시됩니다.
- file:/// 로 시작하는 로컬 파일 경로를 주소 입력란에 넣지 말고 파일 선택 창을 사용해야 합니다.


## v18 상품 이미지 표시 개선
- 상품 등록에서 이미지 파일만 선택하도록 단순화했습니다. 이미지 URL과 구매 페이지 URL 입력란을 제거했습니다.
- 업로드 이미지의 밝은 바깥 여백을 자동으로 감지해 잘라내고, 도면 안에서 가구 영역에 맞춰 비율을 유지하며 표시합니다.
- 사진이 등록된 가구에는 이름/치수 텍스트를 이미지 위에 겹쳐 표시하지 않습니다.
- 실제 탑뷰가 아닌 정면 상품 사진은 위에서 본 형태로 자동 변환되지 않습니다. 탑뷰 사진을 사용하면 배치도에서 더 자연스럽습니다.


## v19 간단 배경 제거
- 별도 API/크레딧 없이 브라우저 안에서 이미지 가장자리와 연결된 흰색·단색 배경을 flood-fill 방식으로 투명 처리합니다.
- 복잡한 배경을 이해하는 AI 누끼가 아니므로, 흰색/단색 스튜디오 배경 상품 사진에 가장 적합합니다.
- 제거 전 원본으로 되돌리기와 미리보기를 지원합니다.
- 사진은 브라우저에서 처리되며 서버로 업로드하지 않습니다.
