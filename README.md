# 우리집 배치연구소 v3

정적 HTML 가구 배치 도구입니다.

## 파일
- `index.html`: 사이트 화면과 기능
- `floorplan.jpg`: 예시 59A 아파트 도면 배경

## v3 추가 기능: 배치 가능 영역
1. 도면 크기를 기준 길이로 보정합니다.
2. `배치 영역 그리기`를 누릅니다.
3. 배치하려는 방의 벽 안쪽 경계를 따라 꼭짓점을 3개 이상 클릭합니다. 꺾인 방은 모서리마다 점을 추가합니다.
4. `영역 확정`을 누릅니다.
5. 이후 가구 추가, 이동, 크기 수정, 회전, 복제 시 가구 전체가 지정한 영역 안에 들어가는 경우만 허용됩니다.

`영역 지우기`를 누르면 제한이 해제됩니다. 한 번에 하나의 배치 영역만 지정할 수 있습니다. 도면의 벽을 AI가 자동 인식하는 기능은 아니며, 사용자가 도면 위에 영역을 직접 표시해야 합니다. 실제 벽 두께와 치수 오차가 있을 수 있으므로 가구 구매 전 현장 실측을 확인하세요.
