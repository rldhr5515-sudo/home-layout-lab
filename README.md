# 우리집 배치연구소 v11

v10의 기존 기능을 유지하면서 다음을 추가했습니다.
- 도면 확대/축소: +, − 버튼 및 마우스 휠
- 도면 이동: 손바닥 이동 모드에서 드래그
- 모바일 핀치 확대/축소 및 두 손가락 이동
- 모바일 화면의 버튼/입력 영역 크기와 배치 개선
- 배치도 이미지 공유: 지원 브라우저에서는 공유 메뉴로 PNG 전송, 미지원 브라우저에서는 PNG 다운로드 후 공유

참고:
- 공유는 현재 배치도 PNG 이미지 공유입니다. 웹사이트의 공개 URL이나 편집 가능한 프로젝트를 공유하는 기능은 아닙니다.
- 브라우저/기기에서 Web Share API를 지원하지 않으면 PNG 파일로 저장됩니다.
- 배치 저장은 기존처럼 현재 브라우저 로컬 저장소에 저장됩니다.
