# 우리집 배치연구소

정적 HTML 가구 배치 도구입니다.

## 파일
- `index.html`: 사이트 화면과 기능
- `floorplan.jpg`: 예시로 넣어둔 59A 아파트 도면 배경

## 사용
GitHub 저장소에 두 파일을 모두 올리면 Netlify가 자동 배포합니다. 사이트에서 '아파트 도면 이미지 올리기'로 다른 도면도 배경으로 올릴 수 있습니다.

도면 이미지는 배경으로 표시되며, 자동으로 벽이나 실제 치수를 인식하지는 않습니다. 이미지가 방의 가로·세로 입력 영역에 맞춰 표시되므로 실제 치수와 비율은 사용자가 확인해야 합니다.
