# 우리집 배치연구소 v2

정적 HTML 가구 배치 도구입니다.

## 파일
- `index.html`: 화면과 가구 배치 기능
- `floorplan.jpg`: 기본 예시 59A 아파트 도면

## 주요 기능
- 기본 59A 도면 표시 및 다른 도면 이미지 업로드
- 도면 비율 유지 표시 (기존 고정 방 테두리 제거)
- 기준 길이를 두 점으로 지정해 cm당 화면 픽셀 크기 보정
- 가구 추가, 선택, 드래그 이동, 크기/이름/가격 수정, 90도 회전, 복제, 삭제
- 배치도 PNG 저장 및 예상 구매금액 합계

## 업데이트
GitHub 저장소에 `index.html`과 `floorplan.jpg`를 함께 올려 주세요. 기존 파일은 교체하고, Netlify가 재배포한 뒤 사이트를 새로고침하면 됩니다.

## 크기 보정 방법
1. 도면에 적힌 실제 길이(예: 3200mm)를 cm로 입력합니다(320cm).
2. '기준 길이 지정하기'를 누릅니다.
3. 도면에서 해당 치수 구간의 양 끝점을 차례로 클릭합니다.
4. 보정 후 추가한 가구는 입력한 cm 크기를 기준으로 표시됩니다.

주의: 벽이나 방 구조를 자동 인식하지 않습니다. 기준 길이를 정확히 선택해야 하며, 도면 이미지의 왜곡·해상도·원본 축척에 따라 오차가 생길 수 있습니다. 가구가 벽 안에 있는지 자동 판정하지 않습니다.
