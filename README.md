# 우리집 배치연구소 v7

## v7 추가 기능
- 브라우저 자동 저장(localStorage): 가구, 방 영역, 크기 보정, 사용자가 업로드한 도면을 저장
- 새로고침 후 같은 브라우저에서 자동 복원
- 수동 '배치 저장' 및 '저장된 배치 불러오기' 버튼
- 가구 모양: 사각형, 원형, 둥근 사각형
- 기존 가구의 모양도 선택 후 수정 가능

## 주의
- 저장은 현재 사용하는 브라우저/기기에만 남습니다. 다른 기기나 브라우저와 동기화되지 않습니다.
- 브라우저 데이터/사이트 저장공간을 삭제하면 저장 내용도 사라질 수 있습니다.
- 실제 서버 계정 저장은 아직 구현하지 않았습니다.
- 가구 모양은 평면도에서 단순한 도형으로 표시합니다.
