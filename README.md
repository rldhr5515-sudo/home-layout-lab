# 우리집 배치연구소 v5

정적 HTML 가구 배치 도구입니다.

## 파일
- `index.html`: 화면과 기능
- `floorplan.jpg`: 기본 예시 59A 아파트 도면

## v5 추가 기능
- 가구끼리 겹치는지 실시간 확인
- 겹치는 가구는 빨간색 반투명 채움과 빨간 테두리로 표시
- 겹친 가구 쌍과 겹침 개수를 안내
- 겹침이 없어지면 경고가 자동으로 사라짐

## 사용
1. 기존 GitHub 저장소의 `index.html`과 `floorplan.jpg`를 이 폴더의 파일로 교체합니다.
2. GitHub에 commit하면 Netlify가 자동 배포합니다.
3. 도면을 올리고 기준 길이 보정을 한 뒤, 방별 영역을 지정하고 가구를 배치합니다.
4. 가구가 겹치면 빨간색으로 표시되므로 한 가구를 끌어 옮겨 겹침을 해소합니다.

참고: 겹침 검사는 화면상 가구 사각형끼리의 겹침을 기준으로 합니다. 벽, 문 여닫힘, 실제 통행 폭까지 자동 판단하는 기능은 아닙니다.
